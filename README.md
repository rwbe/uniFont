# UniFont

Transforme texto simples em estilos de tipografia Unicode.

## 🖼️ Demonstração

Veja abaixo um exemplo de como o UniFont transforma o texto:

![Demonstração do UniFont](./screenshot.png)

## 🌟 Funcionalidades

- **21 estilos de tipografia** - Categorias: Serif, Sans, Decorative, Special e Symbols
- **Copiar com um clique** - Toque em qualquer estilo para copiar instantaneamente
- **Filtros por categoria** - Navegue rapidamente pelos estilos por categoria
- **Interface moderna** - Design elegante com animações suaves
- **Responsivo** - Funciona perfeitamente em qualquer dispositivo

## 🔤 Estilos de tipografia

| Categoria  | Estilos                                                         |
| ---------- | --------------------------------------------------------------- |
| Serif      | Serif, Serif Bold, Serif Italic, Serif Bold Italic              |
| Sans       | Sans Serif, Sans Bold, Sans Italic, Sans Bold Italic            |
| Decorative | Script, Script Bold, Fraktur, Fraktur Bold                      |
| Special    | Monospace, Double Struck, Small Caps, Superscript               |
| Symbols    | Circled, Negative Circled, Squared, Negative Squared, Fullwidth |

## 🛠️ Tecnologias

- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**

## 🚀 Como rodar o projeto

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build
```

## 🧠 Como funciona

O UniFont utiliza símbolos alfanuméricos matemáticos Unicode para transformar seu texto. Esses caracteres especiais parecem diferentes mas funcionam como texto normal - você pode colá-los em qualquer lugar que suporte Unicode (redes sociais, aplicativos de mensagens, documentos, etc.).
